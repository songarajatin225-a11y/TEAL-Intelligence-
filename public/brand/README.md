# Brand assets

- `teal-logo.png` — the ORIGINAL TEAL logo ("TEAL — A TATA Enterprise"), taken byte-for-byte from the
  logo embedded in the TEAL laser configurator (`public/legacy/laser-simulator/index.html`). Do not redraw
  or modify it.
- `favicon-32/180/192/512.png` — the TEAL wordmark cropped from that same file and placed on a white
  rounded tile (pixels scaled, never redrawn). Used for the browser tab, home-screen icon and the compact
  sidebar mark.

To replace the logo, overwrite `teal-logo.png` with the new original file and regenerate the favicons.
