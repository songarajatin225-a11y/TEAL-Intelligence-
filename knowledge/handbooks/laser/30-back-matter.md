## B.1 Glossary

| Term | Definition |
|---|---|
| Ablation threshold | Minimum fluence at which material is removed; falls with pulse count (incubation) |
| Absorptance | Fraction of incident light absorbed (1 − R for opaque materials) |
| Accessible emission limit (AEL) | Maximum emission permitted for a laser class |
| Annealing mark | Colour or black mark formed by oxide growth below melting, without material removal |
| Aspect ratio (weld) | Weld depth divided by width; ≤ 1 conduction, up to ~10 keyhole |
| Assist gas | Gas that ejects melt, reacts (O₂) or shields (N₂, Ar) during cutting or welding |
| Beam parameter product (BPP) | Waist radius × far-field half-angle; M²λ/π; conserved by passive optics |
| Bessel beam | Beam with a long, narrow, non-diffracting core, produced with an axicon |
| Brightness (radiance) | Power per unit area per unit solid angle; ≈ P/(M²λ)² |
| Burst mode | Groups of closely spaced ultrafast pulses (MHz–GHz) used to raise removal efficiency |
| Chirped-pulse amplification (CPA) | Stretch–amplify–compress technique for high-peak-power ultrashort pulses |
| Coherence length | Distance over which light keeps a fixed phase relation; ≈ λ²/Δλ |
| Conduction welding | Welding by heat conduction from the surface without a vapour cavity |
| Cross-jet | Transverse air knife that protects optics from spatter |
| D4σ | Second-moment beam diameter defined in ISO 11146 |
| Depth of focus (DOF) | Axial range over which spot size stays within a stated tolerance |
| Diffractive optical element (DOE) | Micro-structured phase plate that reshapes a beam |
| Dross | Re-solidified melt adhering to the bottom edge of a cut |
| Duty cycle | Fraction of time the laser emits: pulse duration × repetition rate |
| Étendue | Area × solid angle of a beam; cannot be reduced by passive optics |
| F-theta lens | Scan lens whose image height is proportional to scan angle, giving a flat field |
| Fluence | Energy per unit area (J/cm²) |
| Fresnel reflection | Reflection at an interface set by refractive indices, angle and polarisation |
| Gain saturation | Reduction of gain as intensity approaches the saturation intensity |
| Galvanometer scanner | Pair of motor-driven mirrors that steer a beam in X and Y |
| Hatch spacing | Distance between adjacent fill lines in area processing |
| Heat-affected zone (HAZ) | Region whose microstructure or properties changed by heat without melting |
| Incubation | Decrease of damage or ablation threshold with repeated pulses |
| Intensity (irradiance) | Power per unit area (W/cm²) |
| Isolator | Faraday device that transmits forward light and blocks back-reflection |
| Kerf | Width of material removed by a cut |
| Keyhole | Vapour cavity in the melt pool that enables deep penetration welding |
| Laser-induced damage threshold (LIDT) | Fluence or power density at which an optic is damaged (ISO 21254) |
| Longitudinal mode | Standing-wave frequency of a cavity; spaced by c/2nL |
| M² | Beam propagation ratio relative to an ideal Gaussian (ISO 11146) |
| Maximum permissible exposure (MPE) | Highest exposure considered safe for eye or skin |
| Metastable level | Long-lived excited state that stores energy for lasing |
| Mode-locking | Phase-locking of longitudinal modes to generate ultrashort pulse trains |
| MOPA | Master oscillator power amplifier: seed pulses shaped at low power, then amplified |
| Nominal ocular hazard distance (NOHD) | Distance beyond which exposure falls below the MPE |
| Numerical aperture (NA) | Sine of the acceptance or divergence half-angle (× index) |
| Optical density (OD) | log₁₀ of attenuation of protective eyewear or filters |
| Output coupler | Partially transmitting cavity mirror that extracts the beam |
| Overlap (pulse, hatch) | Fraction by which successive spots or lines overlap |
| Peak power | Pulse energy divided by pulse duration (× shape factor) |
| Phase matching | Condition for efficient harmonic generation in nonlinear crystals (Δk = 0) |
| Population inversion | More atoms in the upper than the lower laser level; required for gain |
| Process fiber | Fiber cable from coupler or source to the process head |
| Position-synchronised output (PSO) | Laser firing triggered by actual axis position |
| Q-switching | Holding cavity loss high to store energy, then releasing a short, intense pulse |
| QCW | Quasi-CW: CW architecture operated in long (ms) high-peak pulses |
| Quantum defect | Fraction of pump photon energy lost as heat: 1 − λ_pump/λ_laser |
| Rayleigh range | Distance from the waist at which the beam area doubles |
| Recast layer | Re-solidified melt on the walls of holes or cuts |
| Skywriting | Scanner motion that accelerates outside vectors so marking occurs at constant speed |
| Spallation | Removal by stress-induced fracture rather than vaporisation |
| Stealth dicing | Sub-surface laser modification inside a wafer followed by tape expansion |
| Telecentric lens | Lens whose chief rays strike the work surface perpendicularly across the field |
| Thermal diffusion length | ≈ 2√(κτ): how far heat spreads during interaction time τ |
| Thermal lensing | Focal change caused by absorption-induced temperature gradients in optics or gain media |
| Threshold (laser) | Pump level at which round-trip gain equals loss |
| Top-hat | Beam with near-uniform intensity across its profile |
| Wall-plug efficiency | Optical output power divided by electrical input power |
| Wetting | Spreading of molten solder or filler on a surface |
| Wobble welding | Welding with a superimposed oscillating beam path |

## B.7 Safety checklist

☐ Risk assessment per ISO 12100 completed and documented

☐ Product classified per IEC 60825-1; labels and user information complete

☐ Class 1 enclosure verified against the worst-case beam; guards and windows rated for wavelength and power (IEC 60825-4)

☐ Interlocks on every access panel; guard locking where needed

☐ Safety functions implemented to the required performance level (ISO 13849-1) and validated

☐ Key switch, emergency stop, emission indicators and remote interlock fitted

☐ Redundant, monitored beam shutter independent of the source’s own control

☐ Fume extraction sized, filtered and interlocked; approved-materials list (no PVC)

☐ Fire risk controlled: non-combustible enclosure, spark arrestor, detection in filters

☐ Electrical design to IEC 60204-1; lock-out/tag-out and HV discharge procedures

☐ Service procedure, controlled area, laser safety officer, eyewear with calculated OD

☐ Collateral radiation assessed (plasma UV/blue light; X-rays for high-intensity ultrafast)

☐ Training records and periodic inspection of interlocks, windows and extraction

## B.8 Product manager, application engineer and POC checklists

Product manager

☐ Customer problem, volume and value quantified

☐ URS complete and every line testable

☐ Feasibility proven on real parts (POC report)

☐ Technology choice defended against laser and non-laser alternatives

☐ Target cost, costed BOM and make/buy decisions

☐ Supply risks reviewed: lead times, single sources, export controls

☐ Customer cost per part and ROI modelled

☐ Compliance route planned (CE, UL, FDA, SEMI as applicable)

☐ Software, data and MES requirements specified

☐ FAT and SAT protocols agreed

☐ Service, spares, training and warranty plan costed

☐ Pricing and competitive positioning set

Application engineer

☐ Material identified and certified; surface state and coatings recorded

☐ Absorption at candidate wavelengths checked (§9.2–9.3)

☐ Thermal budget and HAZ estimated (§9.4)

☐ Spot, DOF and field computed; fixture tolerance fits inside DOF

☐ Power measured at the workpiece before testing

☐ Focus verified with a ramp test

☐ DOE designed with responses and metrology defined

☐ Results recorded in derived quantities (fluence, J/mm, overlap)

☐ Robustness to noise factors tested

☐ Cycle time split into process, handling and vision

☐ Recipe documented and version-controlled

Proof of concept

☐ Objective and acceptance criteria agreed in writing with the customer

☐ Representative parts, ideally from several material lots

☐ Laser and optics configuration matches the proposed machine

☐ Sample plan and metrology defined (cross-sections, grading, mechanical and functional tests)

☐ Parameter window with margins identified, not a single operating point

☐ Cycle time demonstrated or credibly extrapolated

☐ Risks and open questions listed

☐ Report with photos, data, recommended machine concept and decision requested

## B.10 Laser Technology at a Glance

| Layer | Decision | Governing rule | Numbers to remember |
|---|---|---|---|
| Photon | Which wavelength | The material must absorb it: E[eV] ≈ 1240/λ[nm] | Si edge ~1.1 µm; Cu absorbs ~4% at 1 µm vs ~40% at 515 nm |
| Source | Which family | Match wavelength, pulse regime and power at the lowest cost per part | Fiber 35–50% wall-plug; CO₂ 10–20% |
| Pulse | Which regime | Thermal diffusion length 2√(κτ) must be below the allowed HAZ | Steel: 1 ms → ~130 µm; 100 ns → ~1.3 µm; 10 ps → ~13 nm |
| Beam | Which spot | d₀ = 4M²λf/(πD); DOF ∝ d₀²/(M²λ); BPP is conserved | 1064 nm, f 160 mm, D 7 mm → 40 µm spot, 2z_R ≈ 1.8 mm |
| Delivery and scanning | Fiber or mirrors; galvo or head | Silica fiber 0.3–2.2 µm only; CO₂ uses mirrors | QBH ~10–15 kW, QD ~20 kW; galvo marking 1–5 m/s |
| Process | Which mechanism | Intensity × interaction time (§9.7) | Keyhole ≳ 10⁶ W/cm²; ultrafast 10¹²–10¹⁴ W/cm² |
| Machine | Which architecture | Class 1 enclosure; vision → position → process → inspect; MES | Cycle time usually set by handling and vision |
| Business | Is it worth it | Cost per good part = (capex × CRF + opex) / good parts | OEE and cycle time outweigh laser price |
