# Case studies

Ten reference designs, each presented as a case sheet covering requirement, process, UPH, architecture, modules, every engineering discipline, BOM, cost, cycle time, risk, FAT, SAT and service. Copy the reasoning, not the numbers: all figures are indicative planning values for 2026 Indian builds, and every case must be re-run with the real product, rate and CTQs.

In this book

Case 1 — Automatic laser marking machine (EV motor housings)

Case 2 — Laser welding machine (stainless sensor housings)

Case 3 — PCB laser marking machine (inline SMT)

Case 4 — Semiconductor package marking machine (leadframe strips)

Case 5 — Wafer handling and inspection machine

Case 6 — Battery busbar laser welding machine (prismatic modules)

Case 7 — Robotic assembly cell (power connector)

Case 8 — Vision inspection machine (cylindrical cells)

Case 9 — High-speed pick-and-place machine (IC packages, tray to tape)

Case 10 — Complete semiconductor ATMP back-end line
